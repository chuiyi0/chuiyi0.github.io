# 自然美式英语离线音频

本版使用预先生成的 Microsoft Jenny 美式英语神经语音（en-US-JennyNeural），语速 -5%。不是人工录音。手机和离线 HTML 播放已有 MP3，不连接语音服务，也不运行语音模型。

音频为 24 kHz、单声道、24 kbps MP3。按句子时间边界校验和分段，保留静音边缘和词内停顿；返回的分段数或单词不符时，逐词重新生成。音频分块便于快速加载，导出时仍生成一个 JSON 语音包。

词书有 7375 个词条，其中一个单词有大小写重复。age 和 add 仅作为词族参考，不进入独立学习，不显示朗读按钮；内置音频不包含它们。其余 7373 个学习词条由 7372 段音频覆盖。

“仅保留在词族”是编辑端的词书设置，会随词书导出。导出语音包只包含当前词书参与独立学习且已有音频的词；词族参考词和已删除词不会再次导出。新增自定义单词需要补充音频。

重建：安装 Python 3.12、FFmpeg，执行 pip install -r requirements-voice.txt 和 python build-natural-voice.py。构建阶段需要网络，成品发音完全离线。生成缓存可复用。若自行更换词书，重建前同步词族参考规则。

参考实现：https://github.com/rany2/edge-tts 。不含服务访问凭据，不保留原 meSpeak/eSpeak 引擎。
